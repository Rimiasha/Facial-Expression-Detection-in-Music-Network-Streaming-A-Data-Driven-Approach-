# Facial-Expression-Detection-in-Music-Network-Streaming-A-Data-Driven-Approach-

## Overview

This project demonstrates a Facial Expression Detection and Emotion-Based Music Recommendation System using Convolutional Neural Networks (CNNs), computer vision, and machine learning. The system analyzes a user's facial expressions in real time, classifies their emotional state, and dynamically recommends music from emotion-based playlists.

## Dataset

The project uses the FER2013 facial expression dataset, obtained from Kaggle, for training and evaluating the facial expression recognition model.

## Technologies Used
**📌 Python** 

**📌 Keras (CNN model development and emotion classification)**

**📌 NumPy (Numerical and image-data processing)**

**📌 Streamlit (Interactive web application development)**

**📌 CNN (Facial expression feature extraction and classification)**
